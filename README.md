# 🌍 WorldPulse AI

AI-powered global events intelligence dashboard.

WorldPulse AI aggregates public global event data and news, 
uses AI to structure and summarize information, and presents 
the results through an interactive geospatial analytics dashboard.

## 🚧 Project Status

Currently in development.

## Tech Stack

- React
- Python
- FastAPI
- PostgreSQL
- AI/LLM APIs
- Leaflet
- Pandas

## Planned Features

- Interactive global event map
- Live event feed
- AI-powered event classification
- AI-generated summaries
- Regional risk analytics
- Event trends and statistics
